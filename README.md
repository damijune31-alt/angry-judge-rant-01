A tiny Python program that writes one short, furious rant — about a robot demanding you prove you are not a robot, one blurry traffic light at a time — to `/output/entry.txt`, for make.fun's Angry Judge to read two at a time and pick the one that lands hardest.

## Run it

```sh
python3 main.py
```
